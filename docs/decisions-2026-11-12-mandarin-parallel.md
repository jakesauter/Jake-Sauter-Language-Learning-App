# Mandarin follows Cantonese and Taishanese (2026-11-12)

Feedback from a family member after seeing "How old is he?": "Mandarin should mimic Taishanese and Cantonese." The card showed 佢幾歲呀 / 佢幾歲啊, but Mandarin said 他多大了 ("he how big"), so the word lines crossed and the shared words were hidden.

## Rule applied

Mandarin copies the Cantonese/Taishanese word order and uses the shared (cognate) word **whenever that is still everyday spoken Mandarin**. Where Mandarin really says it differently, the Mandarin stays natural.

Reviewed all 492 cards by hand; changed 280.

## Patterns changed

| Pattern | Before | After |
|---|---|---|
| Same words where Mandarin has them | 他多大了 | 他几岁了 (几岁 = 幾歲) |
| X-not-X questions like Cantonese 唔 questions | 你冷吗, 你会游泳吗 | 你冷不冷, 你会不会游泳 |
| "yet?" questions (未 / 唔曾) | 你吃饭了吗 | 你吃了饭没有 |
| 有冇 questions | 你去过中国吗 | 你有没有去过中国 |
| 等我 "let me" | 我来帮你拿 | 让我帮你拿 |
| 好 as "very" | 我很累, 这个真新鲜 | 我好累, 这个好新鲜 |
| Same verb when Mandarin has it | 做饭, 头疼, 说 | 煮饭, 头痛, 讲 |
| Same word order | 请把酱油递给我, 开车小心 | 请递酱油给我, 小心开车 |
| Same family words | 奶奶 for 婆婆, 兄弟 for 哥哥 | 外婆, 哥哥 |
| Same everyday words | 粤语, 自行车, 抱歉, 帮助 | 广东话, 单车, 对不起, 帮忙 |

## Kept different on purpose (Mandarin doesn't say it the Cantonese way)

- 你叫什么名字 (not 叫什么名): Mandarin needs 名字.
- 在这儿左转, 直走然后右转 (not 转左/转右).
- 吃饭前先洗手: Mandarin 先 goes before the verb, not at the end.
- 多吃点菜: Mandarin puts 多 before the verb.
- 早上好 for 早晨, 好久不见 for 好耐冇見, 干杯 for 飲勝: fixed Mandarin phrases.
- 别把饭煮糊了, 你把我的钥匙放哪儿了: these need 把 in Mandarin.
- 今天天气很好 (not 好好): 好好 is ambiguous here.
- Cantonese-only words stay Mandarin: 外套 for 褸, 冰箱 for 雪櫃, 吃点心 for 飲茶.

## Other decisions

- The "Compare with Google" lines (g_cmn) were not changed. They are Google's own output, so "How old is he?" still shows 他多大了 there, which is a useful contrast.
- Card notes that described the old Mandarin were rewritten: soy sauce, carry, careful driving, almost there, try this, still hungry, freezing, biking, How old is he? (now mentions 几岁 for children and 多大年纪 for elders).
- Three older notes showed Cantonese or Taishanese readings on Mandarin words (好, 口, 泡茶, and 沖茶 with a Taishanese reading); fixed by adding the reading inline.
- Pinyin follows the existing conventions: 一/不 tone changes are written (yí xià, bú yào), and the middle syllable of X-not-X is unstressed (yào bu yào). Every syllable was checked against CC-CEDICT.
- Some changes make the Mandarin more southern and colloquial (好 for "very", 单车, 礼拜, 煮饭). All are common spoken Mandarin. They suit a family that speaks Cantonese and Taishanese.
